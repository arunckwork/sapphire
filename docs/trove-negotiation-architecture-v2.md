## 1. Mismatch Corrections (DB vs. Concept)

We have identified and resolved the following structural mismatches between the initial high-level conceptual design and your actual codebase:

1. **Status Alignment (Critical):**
   * *Mismatched Concept:* The previous guide assumed statuses like `'REGISTERED'`, `'PENDING_REVIEW'`, `'APPROVED'`, and `'DECLINED'`.
   * *Actual Codebase:* The `gem_collections_collection` status field uses `'review'` (default on creation) and `'accepted'` (set on approval) [208, 220]. 
   * *Correction:* All transition validations and Django ORM filters in this revised guide have been updated to use the exact lowercase values `'review'` and `'accepted'`.

2. **Locked Price Field Name:**
   * *Mismatched Concept:* The previous guide used `final_agreed_price` and `finalized_price` interchangeably.
   * *Actual Codebase:* The schema explicitly uses `finalized_price` (of type `numeric(15,2)`) [274].
   * *Correction:* The Django model and API views now use `finalized_price` exclusively to avoid database migration errors.

3. **Database PK Types:**
   * *Mismatched Concept:* The previous guide assumed a separate `purchase_cases` table with its own fields.
   * *Actual Codebase:* The Django database maintains the lifecycle directly on the `public.gem_collections_collection` table, which uses a `uuid` primary key [274], while referencing the user table (`public.users_user`) which uses a `bigint` auto-incrementing key [277].
   * *Correction:* Our negotiation log table now maps directly to your existing `gem_collections_collection.id` (using UUID) and `users_user.id` (using BigInt) [274, 277].

## 2. Corrected Database Schema

This DDL script creates an immutable, audit-safe negotiation chat log linked directly to your actual PostgreSQL tables.

```sql
-- Create an audit-compliant negotiation ledger linked to your actual tables
CREATE TABLE public.gem_collections_negotiation_log (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    collection_id uuid NOT NULL,
    sender_id bigint NOT NULL,
    message_text text NOT NULL,
    
    -- Captures numerical counter-offers proposed during live discussion
    counter_offer_price numeric(15,2) DEFAULT NULL,
    created_at timestamp with time zone NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT gem_collections_negotiation_log_pkey PRIMARY KEY (id),
    
    -- Links to your actual collections table. Cascade deletes messages if a collection is deleted.
    CONSTRAINT fk_negotiation_collection FOREIGN KEY (collection_id) 
        REFERENCES public.gem_collections_collection(id) ON DELETE CASCADE,
        
    -- Links to your actual user table. Prevent user deletion if they have signed audit logs.
    CONSTRAINT fk_negotiation_sender FOREIGN KEY (sender_id) 
        REFERENCES public.users_user(id) ON DELETE RESTRICT
);

-- Index for speedy retrieval when loading chat history in the frontend app
CREATE INDEX gem_collections_negotiation_log_collection_id_idx 
    ON public.gem_collections_negotiation_log USING btree (collection_id);

-- Enforce Read-Only Immutability: Prevent message tampering (retains strict audit trail)
REVOKE UPDATE, DELETE ON public.gem_collections_negotiation_log FROM PUBLIC;
```

## 3. Django ORM Implementation (`models.py`)

Add this class directly to your `gem_collections/models.py` file. It incorporates strict validation to block any negotiation entries once the collection has been accepted.

```python
import uuid
from django.db import models
from django.conf import settings
from django.core.exceptions import ValidationError

class CollectionNegotiationLog(models.Model):
    # Generates a standard auto-incrementing bigint PK to match your users_user pattern
    id = models.BigAutoField(primary_key=True)
    
    # Links to your existing uuid-based Collection model
    collection = models.ForeignKey(
        'Collection', 
        on_delete=models.CASCADE, 
        related_name='negotiation_logs'
    )
    
    # Links to your custom users_user model (protected from delete to preserve audits)
    sender = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.PROTECT,
        related_name='negotiation_messages'
    )
    message_text = models.TextField()
    counter_offer_price = models.DecimalField(
        max_digits=15, 
        decimal_places=2, 
        null=True, 
        blank=True
    )
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        db_table = 'gem_collections_negotiation_log'
        ordering = ['created_at']

    def clean(self):
        # Prevent appending messages once collection is accepted and barcode/voucher are generated
        if self.collection.status == 'accepted':
            raise ValidationError(
                "This collection has already been accepted and finalized. "
                "No further negotiation notes can be added."
            )

    def save(self, *args, **kwargs):
        self.full_clean()
        super().save(*args, **kwargs)

    def __str__(self):
        return f"Message by {self.sender.username} on Collection {self.collection.serial_no}"
```

User = get_user_model()

class NegotiationSenderSerializer(serializers.ModelSerializer):

        model = CollectionNegotiationLog

### Views (`views.py`)
```python
from django.shortcuts import get_object_or_safe
from rest_framework import status, permissions
from rest_framework.views import APIView
from rest_framework.response import Response
from .models import Collection, CollectionNegotiationLog
from .serializers import CollectionNegotiationLogSerializer

class CollectionNegotiationLogView(APIView):
    permission_classes = [permissions.IsAuthenticated]

    def get(self, request, collection_id):
        # Fetch log history for the collection
        collection = get_object_or_404(Collection, id=collection_id)
        logs = collection.negotiation_logs.all()
        serializer = CollectionNegotiationLogSerializer(logs, many=True)
        return Response(serializer.data, status=status.HTTP_200_OK)

    def post(self, request, collection_id):
        collection = get_object_or_404(Collection, id=collection_id)
        
        # Build serializer and assign current logged-in user as the sender
        serializer = CollectionNegotiationLogSerializer(data=request.data)
        if serializer.is_valid():
            try:
                # instantiate model first to trigger clean() validations
                log_entry = CollectionNegotiationLog(
                    collection=collection,
                    sender=request.user,
                    message_text=serializer.validated_data['message_text'],
                    counter_offer_price=serializer.validated_data.get('counter_offer_price')
                )
                log_entry.full_clean() # Runs clean() method to prevent writing on 'accepted' deals
                log_entry.save()
                
                # Re-serialize for return body
                return Response(
                    CollectionNegotiationLogSerializer(log_entry).data, 
                    status=status.HTTP_201_CREATED
                )
            except Exception as e:
                return Response(
                    {"error": str(e)}, 
                    status=status.HTTP_400_BAD_REQUEST
                )
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

## 6. How Final Acceptance Syncs with Your Current v2 API

When the manager/senior approver decides to finalize the purchase based on the negotiation logs:
1. They call your existing **`PATCH /api/v1/collections/:id/review`** endpoint [214, 222].
2. The payload contains the final negotiated price (passed into `finalized_price`) and the preferred `payment_method` (e.g. `'cash'`, `'mobile_money'`, or `'bank_transfer'`) [214, 222].
3. On database write:
   - `status` updates to `'accepted'` [214, 222].
   - `finalized_price` locks the last agreed offer [214, 222].
   - The PDF payment voucher is generated based on this `finalized_price` [259, 260].
   - **Immutability Trigger:** The model clean functions lock the collection record, preventing any subsequent modification to prices, details, or negotiation logs [100].
